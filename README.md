# qa_dock

Базовый проект для QA окружения и тестирования.

## Структура проекта

```text
qa_dock/
├── .env.example          # Пример конфигурации переменных окружения
├── .env                  # Локальные переменные окружения (игнорируются в git)
├── .gitignore            # Исключения для Git
├── Dockerfile            # Базовый Dockerfile
├── docker-compose.yml    # Конфигурация Docker Compose
├── config/               # Конфигурационные файлы
├── src/                  # Исходный код / утилиты
└── tests/                # Тестовые сценарии / автотесты
```

## Быстрый старт

### 1. Настройка переменных окружения
Скопируйте пример файла конфигурации (если `.env` еще не создан):
```bash
cp .env.example .env
```

### 2. Запуск через Docker Compose
Сборка и запуск контейнеров в фоновом режиме:
```bash
docker-compose up -d --build
```

Просмотр логов:
```bash
docker-compose logs -f
```

Остановка контейнеров:
```bash
docker-compose down
```
